# Vault Lens releases

Vault Lens is a Windows desktop app for browsing an Autodesk Vault read-only and viewing its files, without using a Vault or Inventor license.

This repository holds the released versions of the app and nothing else. The newest is under [Releases](https://github.com/johanmcad/Vault-Lens-releases/releases/latest).

- Download `VaultLens.App.exe` from the release and run it. There is no installer.
- `THIRD-PARTY-NOTICES.md` in each release lists the open-source parts inside the exe and their licences.
- The app checks this page at start and tells you when a newer version is here. It downloads nothing by itself.
